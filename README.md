# 🌐 GoDaddy Clone - Functional Domain Registration Platform

A fully functional GoDaddy-inspired domain registration platform where users can search for domains, check availability, add to cart, and manage their registered domains. Built with HTML, CSS, and JavaScript.

## 🌟 Features

### Domain Search & Registration
- ✅ **Domain Search**: Search for available domain names
- ✅ **Availability Checker**: Real-time domain availability simulation
- ✅ **Multiple Extensions**: Support for .com, .net, .org, .io, .co, .info
- ✅ **Pricing Display**: Clear pricing for each domain extension
- ✅ **Add to Cart**: Shopping cart functionality

### Shopping Cart
- ✅ **Cart Management**: Add/remove domains from cart
- ✅ **Price Calculation**: Automatic total calculation
- ✅ **Checkout Process**: Simulated checkout with domain registration
- ✅ **Persistent Cart**: Cart data saved in localStorage

### User Dashboard
- ✅ **My Domains**: View all registered domains
- ✅ **Domain Management**: Renew and manage domains
- ✅ **Registration Details**: View registration and expiry dates
- ✅ **Account Settings**: Update user information

### Additional Features
- ✅ **Responsive Design**: Works on desktop, tablet, and mobile
- ✅ **Modern UI**: Clean, professional design inspired by GoDaddy
- ✅ **Promotions Section**: Display special offers
- ✅ **Web Hosting Plans**: Hosting plan showcase
- ✅ **Smooth Navigation**: Single-page application behavior
